HS SCS Encoder

Gira el mando para ajustar y pulsa para la accion indicada en la accion.

Asignacion automatica: si tu perfil no tiene tecla para crucero +/- o retarder +/-, el plugin agrega una tecla libre cuando cierras el juego. Nunca pisa bindings existentes y guarda un backup. Espera unos segundos y reinicia el juego para que SCS lea el cambio.

Tambien puedes asignar las teclas manualmente en Opciones > Teclas; el plugin usara las que ya existan. El pulso del encoder de crucero activa el control (C), el de retarder usa el freno motor (B) y el de volumen silencia.
